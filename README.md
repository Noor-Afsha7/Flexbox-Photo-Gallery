# Flexbox Photo Gallery

A simple and responsive photo gallery created using HTML and CSS Flexbox. This project demonstrates how Flexbox can be used to build a clean image gallery layout that adapts to different screen sizes.

## Features

- Responsive Flexbox layout
- Automatic image wrapping
- Consistent spacing using Flexbox gap
- Uniform image dimensions with `object-fit: cover`
- Rounded image corners
- Centered gallery container
- Modern and clean design

## Technologies Used

- HTML5
- CSS3 (Flexbox)

## Project Structure

├── flexbox-photo-gallery.html
├── flexbox-photo-gallery.css

## How It Works

The gallery uses:

- `display: flex` to create a flexible layout
- `flex-wrap: wrap` to move images onto new rows when needed
- `justify-content: center` to center images horizontally
- `align-items: center` to align items properly
- `gap` to maintain equal spacing between images
- `object-fit: cover` to ensure images maintain their appearance without distortion
